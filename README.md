# zaverecny_projekt
Moje aplikace bude sloužit k monitorování každodenní aktivity uživatele. Umožňuje sledovat počet kroků, odhad spálených kalorií a zaznamenávat pitný režim. Cílem je nabídnout jednoduchý a přehledný nástroj pro podporu zdravého životního stylu. Udělám taky žebříček, který bude fungovat jako úrovně 1-10  (1-začátečník, 10-expert)
